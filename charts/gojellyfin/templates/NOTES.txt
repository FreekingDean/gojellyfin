DATABASE_URL comes from the Secret {{ include "gojellyfin.databaseSecretName" . }}, key {{ .Values.database.secretKey }}. Create it before the pods start:

  kubectl --namespace {{ .Release.Namespace }} create secret generic {{ include "gojellyfin.databaseSecretName" . }} \
    --from-literal {{ .Values.database.secretKey }}='postgres://user:password@host:5432/gojellyfin?sslmode=require'

  kubectl --namespace {{ .Release.Namespace }} run gojellyfin-migrate --rm --attach --restart Never \

    --env DATABASE_URL="$DATABASE_URL" -- migrate

or set migration.enabled=true to have the chart run it.

  kubectl --namespace {{ .Release.Namespace }} exec -i deploy/{{ include "gojellyfin.fullname" . }} -- gojellyfin adduser <name>
