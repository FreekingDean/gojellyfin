# Using gojellyfin

gojellyfin uses the Jellyfin API, so you can connect with compatible Jellyfin
clients. Your media libraries are built from your existing media managers.

- [Connect your libraries](libraries.md) with Radarr, Sonarr and Lidarr.
- [Understand playback](playback.md), including direct play, remuxing and transcoding.
- [Live TV and SyncPlay](live-tv-and-syncplay.md) — what is supported and where the boundaries are.

The project is still evolving. These pages describe the current implementation,
not every feature available in Jellyfin.
